# YSGAudioTools (구 주소 유지용)

허브 저장소를 **`YSGAudioLabs`** 로 이름을 바꾸면서 Pages 주소가 바뀌었다.
GitHub 은 저장소 URL 은 리다이렉트해주지만 **Pages 경로는 리다이렉트하지 않는다.**

이미 배포된 데스크톱 앱(SoundField · Stereo Auditor · Wwise Attenuation/Bus Routing
Auditor)은 허브 주소를 `https://samter96.github.io/YSGAudioTools/index.html` 로
**빌드에 박아** 들고 나갔다. 소스를 고쳐도 이미 설치된 앱은 업데이트 전까지 고쳐지지
않는다. 그래서 옛 주소 자체를 살려둔다.

- `index.html` — 허브 루트로 이동
- `404.html`   — 그 밖의 모든 경로를 **경로를 유지한 채** 새 위치로 이동
                 (`/YSGAudioTools/soundfield/` → `/YSGAudioLabs/soundfield/`)

⚠ 이 저장소를 지우면 기존 빌드의 허브 버튼이 다시 404 가 된다.

실제 사이트: https://github.com/samter96/YSGAudioLabs
