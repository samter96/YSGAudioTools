04 · channel order

같은 5.1인데 채널 순서가 다른 파일을 가려낸다

5.1·7.1은 채널이 담기는 순서가 두 갈래로 돌아다닙니다. 영화 계열은 L·C·R·Lb·Rb·LFE, 윈도우 계열은 L·R·C·LFE·Lb·Rb 순인데 파일 헤더만으로는 어느 쪽인지 알 수 없는 경우가 많습니다. 순서를 잘못 잡으면 중앙이 한쪽으로 쏠리고 LFE가 스피커 자리에 들어갑니다. 그래서 두 순서를 번갈아 들려주고, 고른 값을 파일 하나에만 저장하거나 그 폴더의 같은 채널 수 파일 전체에 한 번에 적용할 수 있습니다.

What it is

찾고 · 듣고 · 잘라내는 것에만 집중한 검색 툴

DAW를 열지 않고도 방대한 사운드 라이브러리에서 원하는 소리를 빠르게 찾아, 바로 듣고, 필요한 부분을 내보내기까지 한 창에서 끝냅니다.

라이브러리가 수 TB로 커지면 탐색기·DAW 브라우저로는 원하는 소리를 찾는 데 시간이 오래 걸립니다. SoundField는 모든 오디오 파일을 한 번 색인(index)해 두고, 이후에는 파일명·경로·메타데이터를 가로질러 즉시 검색합니다.

검색 결과는 그 자리에서 파형과 함께 재생되고, 마음에 드는 구간을 드래그해 잘라 내보내거나 DAW로 바로 드래그할 수 있습니다. 색인은 전부 로컬에 저장되며, 원본 라이브러리 폴더에는 어떤 파일도 쓰지 않습니다.

핵심 가치

  • 즉시 검색 — FTS 색인 기반, 타이핑과 동시에 결과
  • 바로 오디션 — 결과 클릭 → 파형 + 재생
  • 구간 내보내기 — 드래그로 자르고 원본 청크 보존

설계 원칙

  • 읽기 전용 — 원본 라이브러리 절대 수정 안 함
  • 로컬 인덱스 — 각자 로컬에 색인 저장
  • 중단 안전 — 인덱싱 취소·재개 시 진행분 보존

Indexing

1단계는 아주 빠르게 — 먼저 검색 가능한 목록을 만든다

Phase 1은 파일명과 경로 중심의 목록 색인만 빠르게 끝내 검색 진입을 먼저 열고, Phase 2가 뒤에서 상세 메타데이터를 채워 고급 검색을 완성합니다. 진행 중 언제든 취소할 수 있고, 이미 끝난 진행분은 보존됩니다.

Phase 1 advantage

먼저 파일 목록만 초고속으로 색인합니다. 메타데이터 분석을 기다리지 않아도 이름/경로 기반 검색과 오디션 진입이 빠르게 열립니다.

Phase 2 enrich

이후 길이, 샘플레이트, 채널, 태그 같은 메타데이터를 천천히 채워 넣어 고급 검색 정확도를 높입니다.

결과 비교 — 파일명, 길이, 샘플레이트, 채널, 경로를 한 화면에서 바로 훑습니다.

오디션 연결 — 결과를 선택하면 아래 파형과 재생 컨트롤로 바로 이어집니다.

즉시성 — 색인 기반이라 타이핑과 거의 동시에 결과가 갱신됩니다.

Library browser

여러 라이브러리를 한 트리에서 넘나든다

여러 저장 위치를 라이브러리로 등록해 하나의 폴더 트리로 관리하고, 탭으로 작업 맥락을 분리합니다.

Multi-library tabs

전체 목록에서 내 작업 탭으로 라이브러리를 담는다

원본 라이브러리는 전체 탭에 그대로 두고, 작업에 필요한 라이브러리만 별도 탭에 모아 탐색 범위를 좁힙니다.

브라우저 기능

다중 라이브러리 — 여러 root를 등록, 같은 드라이브는 자동 그룹핑.

탭 — ‘전체 / 즐겨찾기 / 사용자 지정’ 탭으로 맥락 분리(여러 줄 자동 배치).

고정 헤더 — 하위 폴더로 스크롤해도 상위 폴더가 상단에 고정 표시.

블랙리스트 — 특정 경로를 사유와 함께 검색·표시에서 제외.

부분 재스캔 — 폴더 우클릭으로 그 하위만 다시 색인할 수 있습니다.

Duplicate review

중복은 삭제가 아니라 검수 목록으로 먼저 모은다

원본을 건드리지 않고 동일 파일 후보를 묶어서 보여주며, 사용자가 안전하게 정리 판단을 할 수 있게 합니다.

중복 검수

중복 자동 탐지 — 같은 파일이 여러 경로에 있으면 묶어서 표시합니다.

정리 — 하나만 남기고 나머지는 검토 후 처리합니다.

검색 제외 — 각 그룹에서 경로가 가장 짧은 1개만 남기고 나머지를 검색에서 뺍니다. 파일도 인덱스도 지우지 않고 검색 결과에만 안 보이게 표시합니다.

제외 관리 — 제외한 항목은 따로 목록으로 남습니다. 전체를 되돌리거나 골라서 되돌릴 수 있고, 되돌리면 즉시 검색 결과에 다시 나타납니다.

안전 — 원본은 지우지 않고 검수 목록으로만 보여줍니다.

Playback & waveform

클릭 한 번으로 파형과 함께 듣는다

결과를 선택하면 곧바로 파형이 그려지고 재생됩니다. 진폭 확대·구간 선택·세그먼트 감지까지 오디션에 필요한 기능을 갖췄습니다.

Audition

검색 결과를 바로 파형으로 듣는다

결과를 선택하면 앱 화면 안에서 재생, 파형, 선택 구간 확인까지 이어져 DAW를 열기 전 빠르게 판단할 수 있습니다.

오디션 도구

전용 재생 엔진 — 저지연 재생 엔진 + 폴백. WAV·MP3·FLAC·AIFF 지원.

파형 표시 — Nuendo/MediaBay 계열의 대칭 파형. 세로(진폭)만 확대하고 가로 시간축은 항상 파일 전체가 한 화면에 들어옵니다.

구간 선택 — 파형을 드래그해 원하는 구간만 재생·내보내기.

세그먼트 감지 — 무음 기준으로 소리 덩어리를 자동 분할해 탐색.

재생 히스토리 — 최근 재생 목록을 슬라이드 드로어로 다시 꺼내기.

배속 재생 — 0.5x ~ 2.0x. 배속을 걸어 둔 채로 구간을 내보내면 그 속도로 렌더한 파일이 만들어집니다.

Segments & history

필요한 구간과 다시 들을 소리를 놓치지 않는다

세그먼트 감지와 재생 히스토리를 함께 보여줘, 들은 소리와 잘라낼 후보를 계속 추적할 수 있습니다.

Region export

필요한 구간만 잘라 내보낸다 — 메타는 그대로

파형에서 고른 구간을 별도 파일로 내보내거나 DAW 타임라인으로 바로 스폿합니다. 원본의 방송용·제작용 청크를 보존해 정보 손실 없이 필요한 부분만 전달합니다.

WAV 구간 내보내기는 원본 오디오의 데이터 청크를 바이트 단위로 잘라내는 방식이라, 다시 인코딩하지 않고 샘플 손실 없이 저장됩니다. MP3·FLAC·AIFF 는 구간 잘라내기를 지원하지 않아, 그 파일들은 원본 전체가 전달됩니다.

방송용 정보(bext), 제작 메타(iXML), 마커(cue) 같은 청크를 그대로 보존해, 잘라낸 파일도 원본의 정보를 유지합니다.

또한 감지된 세그먼트나 선택 구간을 외부 DAW로 드래그 앤 드롭해, 필요한 구간만 타임라인에 바로 스폿할 수 있습니다.

재생 배속을 1.0x 가 아닌 값으로 두고 내보내면 그 속도로 렌더한 별도 파일 (이름_0.45x.wav)이 만들어집니다. 이름이 달라 DAW가 1.0x 원본과 다른 소재로 취급합니다.

보존되는 청크

  • bext — 방송용 메타
  • iXML — 제작 메타
  • cue — 마커 정보

내보내기 방식

  • 구간 드래그 선택
  • WAV 무손실 슬라이스 (그 외 포맷은 원본 전체)
  • DAW 타임라인으로 바로 스폿
Region export

선택한 구간만 DAW로 넘긴다

전체 원본을 복사하지 않고 필요한 세그먼트나 선택 영역만 내보내거나 DAW 타임라인에 바로 스폿합니다.

필요한 구간만 전달

구간 내보내기 — 선택한 파형 구간만 별도 파일로 만들고, bext·iXML·cue 같은 메타 청크는 유지합니다.

DAW로 스폿 — 세그먼트 헤더나 선택 영역을 드래그해 DAW의 원하는 줄에 바로 놓습니다.

무손실 — 원본 전체를 복사하지 않고 해당 구간만 전달합니다.

Themes

세 가지 색상과 세 가지 실제 화면

색상 팔레트와 해당 앱 캡쳐를 한 쌍으로 보여줘, 실제 테마가 어떻게 보이는지 바로 비교할 수 있습니다.

Neutral (회색) 기본

색 간섭이 적은 무채색 테마입니다. 가장 차분하고 작업용 도구처럼 보이는 기본 테마입니다.

Neon (다크 네이비)

깊은 네이비 배경에 블루 포인트가 들어간 프로 오디오 톤입니다.

Light (베이지)

밝은 베이지 바탕에 진한 브라운 포인트를 넣은 라이트 테마입니다.
