============================================================

파일명을 정확히 맞추면 페이지가 자동으로 대지한다. 없으면 점선 자리표시 박스가
그대로 남는다 (오류가 아니다).

    app-full.png       2560 x 1400   앱 전체가 한 장에 — 폴더 트리 · 검색 행 ·
                                     결과 표 · 파형 플레이어가 모두 보이게.
                                     이 페이지에서 유일한 큰 이미지다.
    binaural.png       1400 x  620   바이노럴 모니터링 패널. 멀티채널 파일을
                                     물려서 판정된 배치와 A/B 버튼이 보이게.
    indexing.png       1200 x  300   인덱싱 진행 중 — 단계 표시 · 개수 · 예상시간.
                                     상단 진행 영역만 잘라도 된다.
    results.png        1400 x  620   검색 행 + 결과 표. 필터 몇 개를 채운 상태로.
    tree.png            760 x  900   폴더 트리. 탭과 고정된 상위 경로가 보이게.
    duplicate.png      1200 x  700   중복 검수 목록. 그룹 몇 개와 개수가 보이게.
    waveform.png       1400 x  480   파형 플레이어. 드래그한 구간과 세그먼트
                                     표시가 함께 보이게.
    export.png         1200 x  420   구간을 고른 상태 — 내보내기/끌어내기 직전.
    theme-neutral.png  1200 x  740   Neutral 테마 (기본)
    theme-neon.png     1200 x  740   Neon 테마
    theme-light.png    1200 x  740   Light 테마

크기는 권장값이다. 비율만 대충 맞으면 페이지가 알아서 맞춘다. 가로가 권장값보다
작으면 확대되어 흐려지니, 큰 쪽으로 찍는 편이 낫다.

왜 새 폴더(v2)인가
------------------
상위 폴더의 hero.png · *_theme.png · *.gif 는 전부 **PyQt v1.2.6 시절** 화면이다
(타이틀바가 윈도우 기본이고 "V1.2.6" 이 찍혀 있다). 지금 앱은 Tauri 2 라 타이틀바가
자체 크롬(YSG AUDIO TOOLS)으로 바뀌었다. 이름을 그대로 쓰면 옛 화면이 자동으로
올라와 버리므로 폴더를 나눴다. 옛 파일은 지우지 않고 참고용으로 남겨 두었다.

GIF 두 개(play_lite.gif · history_lite.gif)는 합쳐서 22MB 였고 내용도 옛 UI 라
새 페이지에서는 빼고 정지 캡처 자리로 바꿨다. 움직임이 꼭 필요하면 다시 넣을 수
있지만, 페이지 전체 무게를 생각하면 정지 이미지 쪽이 낫다.
