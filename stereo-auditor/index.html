Focused Inspection

확대해도 디테일과 시간축을 함께 유지

고해상도 엔벌로프와 판정 데이터를 분리해 재생 반응성을 유지하면서 최대 32배 확대에서 세부 피크를 보여줍니다. 위상 트랙도 보이는 시간 범위를 따라가며 정상과 지속 위험 구간을 구분합니다.

ZOOM · 32X

고해상도 엔벌로프

전체 보기에서는 가볍게 축약하고, 확대 시 저해상도 이미지를 늘리는 대신 보존된 파형 데이터를 사용합니다.

PHASE · SUSTAINED

의미 있는 위상 위험 구간

저레벨 꼬리와 100ms 미만의 순간 신호는 제외하고, 정상 구간 위에 지속 위험만 주황색으로 표시합니다.

HOVER · DETAIL

구간 수치를 바로 확인

웨이브폼과 위험 구간에 마우스를 올려 시간, 스테레오 강도, Side/Mid, L/R 상관도와 판정 이유를 확인합니다.

Workflow

드롭하고, 판정하고, 필요한 곳만 확대

세션 구성이나 라우팅, 업로드 없이 파일 하나를 빠르게 검수하는 단일 목적 데스크톱 유틸리티입니다.

오디오 파일 드롭

시작 화면에 드롭하거나 현재 웨이브폼 영역에 새 파일을 바로 드롭합니다.

채널 판정 확인

분류, 스테레오 강도, 활성 시간, Side/Mid, 상관도와 채널 밸런스를 확인합니다.

재생하며 확대

파형을 탐색·재생·확대·이동하며 확인합니다. 원본 파일은 끝까지 변경되지 않습니다.
